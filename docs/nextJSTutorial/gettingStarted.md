# Getting Started

## Getting Started?

tutorial의 첫 시작 부분입니다.

## 사전지식

해당 tutorial을 따락가기 위해선 아래의 것들에 대해서 익숙해야 한다고 합니다.

- HTML
- CSS
- JavaScript
- React

React의 경우엔 경험이 없거나 복습이 필요한 경우, [React 기초 과정](https://nextjs.org/learn/react-foundations)을 먼저 거친 후에 해당 tutorial을 시도 하는 것이 좋다고 합니다. 저의 경우엔 React가 익숙치 않은 상황까지는 아니니 next.js tutorial을 먼저 진행하며, 부족한 개념이 있을 떄마다 따로 찾아보며 공부할 예정입니다.
